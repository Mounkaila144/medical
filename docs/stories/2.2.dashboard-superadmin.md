# Story 2.2: Dashboard SUPERADMIN dedie

## Status: Ready for Review

## Story

**As a** SUPERADMIN,
**I want** un dashboard affichant uniquement les informations systeme (tenants, utilisateurs, cliniques),
**so that** je puisse gerer la plateforme sans etre distrait par les donnees cliniques.

## Acceptance Criteria

1. Nouvelle page `/admin/dashboard` avec header gradient et message de bienvenue
2. 4 stat cards : Tenants actifs, Total utilisateurs, Cliniques actives, Utilisateurs inactifs
3. Liste des derniers tenants crees avec statut (actif/inactif)
4. Actions rapides : Creer un tenant, Gerer les utilisateurs, Voir les permissions
5. Aucune reference a patients, RDV, revenus ou consultations
6. Apres login d'un SUPERADMIN, redirection automatique vers `/admin/dashboard`

## Dev Notes

### Pattern de dashboard a suivre

Tous les dashboards suivent la meme structure. Copier le pattern de `app/dashboard/page.tsx` :
1. Header gradient avec bienvenue
2. Grille 4 stat cards (`grid gap-3 md:gap-4 grid-cols-2 lg:grid-cols-4`)
3. Widgets detailles
4. Actions rapides en bas

[Source: architecture.md#component-architecture]

### Services a utiliser

- `TenantService.getTenants()` — retourne `Tenant[]`
- `TenantService.getUsers()` — retourne `UserManagement[]`
- Les stats sont calculees localement : `tenants.filter(t => t.isActive).length`, etc.

### Fichiers a modifier
