# Story 2.4: Dashboard et interface ACCOUNTANT

## Status: Ready for Review

## Story

**As a** comptable,
**I want** un espace dedie avec uniquement les outils financiers,
**so that** je puisse gerer la comptabilite sans acceder aux donnees cliniques.

## Acceptance Criteria

1. Dashboard `/accounting/dashboard` avec : Revenus du mois, Depenses du mois, Factures en attente, Solde net
2. Widget repartition des depenses par categorie
3. Widget dernieres factures avec statut (badge colore)
4. Widget derniers paiements recus
5. Actions rapides : Nouvelle depense, Nouvelle facture, Voir les tarifs
6. Apres login d'un ACCOUNTANT, redirection automatique vers `/accounting/dashboard`
7. Le ACCOUNTANT ne peut pas naviguer vers `/patients`, `/encounters`, `/practitioners`

## Dev Notes

### Services a utiliser

- `BillingService.getInvoices()` — liste des factures avec statut
- `BillingService.getPayments()` — liste des paiements
- `ExpenseService.getExpenses()` — liste des depenses
- `ExpenseService.getStats()` — stats (totalExpenses, paidExpenses, pendingExpenses, byCategory)

### Calcul des stats

```typescript
const revenus = payments.reduce((sum, p) => sum + p.amount, 0);
const depenses = expenseStats.totalExpenses;
const facturesEnAttente = invoices.filter(i => i.status === 'DRAFT' || i.status === 'SENT').length;
const soldeNet = revenus - depenses;
```
