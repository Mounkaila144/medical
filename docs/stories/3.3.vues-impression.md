# Story 3.3: Vues d'impression pour prescriptions et factures

## Status: Ready for Review

## Story

**As a** praticien ou comptable,
**I want** pouvoir imprimer une prescription ou une facture avec un format professionnel,
**so that** des documents papier propres soient fournis aux patients.

## Acceptance Criteria

1. Bouton "Imprimer" sur la page detail de prescription et la page detail de facture
2. CSS `@media print` masquant sidebar, header, breadcrumbs
3. En-tete d'impression : nom de la clinique, adresse, telephone, logo
4. Prescription : informations patient, liste des medicaments, signature du praticien, QR code
5. Facture : informations patient, lignes de facturation, totaux, QR code, conditions de paiement
6. Format A4 portrait

### Pattern CSS print

```css
@media print {
  @page { size: A4 portrait; margin: 15mm; }
  .no-print { display: none !important; }
  .print-only { display: block !important; }
}
```

Les elements a cacher doivent avoir la classe `no-print` ou etre cibles par selecteur. Le `MainLayout` sidebar et header peuvent etre cibles par `[data-sidebar]` ou une classe specifique.

### QR code

Les prescriptions et factures ont deja un champ `qr` dans les entites backend. Si le QR est genere (pdfPath + qr), l'afficher dans la vue impression comme image.
