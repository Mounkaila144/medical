# Story 1.5: Nettoyer les services dupliques du frontend

## Status: Ready for Review

## Story

**As a** developpeur,
**I want** supprimer les services dupliques et standardiser sur le pattern apiClient,
**so that** la confusion soit reduite et le refresh token automatique fonctionne sur tous les appels API.

## Acceptance Criteria

1. `services/auth-service.ts` est supprime — toutes les pages utilisent `services/auth.service.ts`
2. `services/appointment-service.ts` est supprime — toutes les pages utilisent `services/appointment.service.ts`
3. `services/api-service.ts` est supprime
4. `services/patient.service.ts` est migre du pattern `fetch + getAuthHeaders()` vers `apiClient`
5. L'import manquant `RegisterData` est resolu (fichier supprime)
6. Aucune page ne reference les anciens services

## Dev Notes

### Services a supprimer

| Fichier | Raison de suppression | Remplacant |
|---------|----------------------|-----------|
| `services/auth-service.ts` | Duplique, utilise ancien pattern `fetch` + `api-config` | `services/auth.service.ts` (utilise `apiClient`) |
| `services/appointment-service.ts` | Duplique, ancien pattern | `services/appointment.service.ts` (utilise `apiClient`) |
| `services/api-service.ts` | Wrapper generique obsolete | `apiClient` directement depuis `lib/api.ts` |

### Migration patient.service.ts

Le fichier `services/patient.service.ts` utilise actuellement le pattern :
```typescript
const API_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:3001';
const headers = { 'Authorization': `Bearer ${localStorage.getItem('accessToken')}` };
const response = await fetch(`${API_URL}/patients`, { headers });
```

Il doit etre migre vers :
```typescript
import { apiClient } from '@/lib/api';
const response = await apiClient.get<Patient[]>('/patients');
```

Cela garantit le refresh token automatique via `TokenManager`. [Source: architecture.md#coding-standards]

### lib/api-config.ts

Ce fichier fournit `API_URL` et `getAuthHeaders()`. Apres suppression des anciens services, verifier qu'aucun autre fichier ne l'importe. Si non utilise, le supprimer aussi.
